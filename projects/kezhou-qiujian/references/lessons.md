# 渲染架構與檢查規則

## 一、渲染架構（build.py）

### 雙通道合成
每格畫面只計算兩張單通道陣列，最後一次上色，速度快（1080p 約 0.2 秒／格）：
- `A`：墨的濃度（0 = 宣紙，1 = 濃墨）
- `R`：朱紅的濃度

上色：`畫面 = 宣紙 × (1−A) + 墨色 × A`，再疊 `朱紅 × R`。墨蓋過朱紅時同時把 `R` 乘上 `(1−墨)`（`put_ink()` 已處理）。

### 共用元件
| 函式 | 用途 |
|---|---|
| `mountain(ridge(...))` | 山巒：脊線、墨色由濃轉淡、直向皴紋、底部霧化 |
| `waves(...)` | 海浪／河面，`storm=True` 為巨浪 |
| `houses` / `trees` / `temple` / `burner` / `boat` / `woman` / `palanquin` / `person` | 2 倍超取樣畫出的水墨剪影 |
| `Crowd` | 預先畫好多種大小的人物，用來排隊伍或人群 |
| `blob` / `glow` / `disc` / `blossom` | 墨點、光暈、太陽、梅花 |
| `incense()` | 閃爍的香火紅點 |
| `InkText` + `text_h` / `text_v` | 墨水暈開式出場的橫書／直書文字（可加 `bold`） |
| `make_seal()` | 朱紅印章（2 字直排、4 字田字格） |
| `load_img()` / `put_img()` | 把 AI 生成的透明背景圖拆成「遮蓋／墨／朱紅」三層合成 |
| `Scene` | 場景基底：`plane()` 平移圖層（視差）、`fx()` 每格自繪、`fog` 霧帶 |
| `Overlay` | 右上直書題字＋印章、底部宣紙色襯底字幕 |
| `Renderer.frame()` | 決定目前場景，換場時用雜訊場做墨暈溶接 |

### 輸出流程
`video` / `draft` 都會把影格切成 8 段，以 multiprocessing 平行渲染成高畫質中間檔再串接；`draft` 單次快速壓縮，`video` 依片長算位元率做兩階段壓縮。

## 二、檢查規則（歷次修正累積）

### 聲音
1. **TTS 會夾帶滿格雜訊**：某些句子開頭約 10ms、結尾約 120ms 有滿格雜訊。`declick()` 會刪除「被安靜段隔開、又短又滿格」的片段；新增 TTS 後跑一次掃描，確認處理後的每句都沒有 >0.95 的峰值。
2. **拼接要淡入淡出**：壓短停頓時每段接點加 6ms 淡入淡出，整句頭尾加 15ms。
3. **削波**：TTS 原始音量可能頂到 1.0，正規化後用 `tanh` 柔性限幅。
4. **使用者回報的時間點**：先對照 `work/timeline.json` 找出是哪一句，再看那句的頭尾；不要只修開頭。
5. **混用模型**：免費額度用完會改用其他模型，交付時要列出哪些句子用了哪個模型。

### 文字
6. **直書要一直線**：標楷體是等寬全形字，每個字用固定起點繪製，**不要依筆畫寬度置中**，否則「一」「元」「○」等字會左右偏移。
7. **缺字**：標楷體沒有「〇」（U+3007），改用「○」（U+25CB）；直書避免括號與破折號。用 fontTools 檢查 cmap。
8. **標題字重**：標楷體沒有粗體，用 `stroke_width` 模擬；大標題約 `bold=2`、墨色 0.88 比較協調，太粗太黑會不搭。
9. **印章不要壓字**：片尾印章放在文字欄位旁的留白處，確認座標不和任何一欄重疊。

### 畫面
10. **行進方向**：船頭、神轎、人群要朝向前進的方向（背景往左捲動時，物體看起來往右走，船頭就要朝右）。
11. **象徵物比例**：放在船上的神像約船寬的 1/4 以下；香火紅點要疊在神像或神轎的中間。
12. **前景要遮擋背景**：懸崖、船身等前景物件要先清掉背後的海浪（occlusion），不能只疊墨。
13. **AI 圖的光暈**：透明背景圖常帶半透明白色光暈，`load_img()` 用 `smooth(alpha, 0.55, 0.97)` 濾掉。
14. **截圖時機**：封面或檢查用截圖要避開墨暈轉場（每個場景交界前後各 0.8 秒）。
15. **數字與年代**：片尾生卒年用中文數字直書，例如「西元九六○年」。

### 輸出
16. **初版／確定版**：初版只做單次快速壓縮；使用者說確定版才做兩階段壓縮。
17. **背景渲染時被打斷**：使用者中途要求修改時，先停止 ffmpeg 與 python 程序並刪除 `work/part*.mp4`，再改程式重跑。
18. **交付時誠實說明**：AI 聽不到聲音，爆音、旁白語氣、字幕對時都要請使用者試聽確認。
