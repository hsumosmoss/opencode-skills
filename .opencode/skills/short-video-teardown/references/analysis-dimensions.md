# 短影音爆款分析維度框架（原抖音電商經驗，適用抖音/TikTok/Reels）

> 提煉自抖音電商實戰經驗；TikTok/Reels 可對照移植，鉤子與轉化設計的平臺慣例略有差異

## 7大分析維度

### 1. 鉤子分析（前3秒）⭐ 最關鍵維度

> 前3秒決定生死。鉤子 = 文案鉤子 + 視覺鉤子，兩條線缺一不可。
> 文案再好，畫面平淡也留不住人；畫面再炸，文案沒鉤也白搭。

**6種文案鉤子型別**：

| 型別 | 定義 | 示例 | 適用場景 |
|------|------|------|---------|
| 反常識 | 打破認知，製造衝突 | 「90%的人洗臉方式都是錯的」 | 科普、測評 |
| 痛點 | 直擊使用者難題 | 「臉上的痘印怎麼都消不掉？」 | 護膚、健康 |
| 資料 | 用具體數字吸引注意 | 「這瓶精華28天淡斑率83%」 | 功效類產品 |
| 場景 | 還原真實生活畫面 | 「每次約會前我都要做這一步」 | 日用、美妝 |
| 懸念 | 留鉤子，激發好奇 | 「千萬別讓你老公知道這個」 | 日用、家居 |
| 利益 | 直接丟擲好處 | 「拍1發6還送贈品」 | 促銷、大促 |

**視覺鉤子型別**（與文案鉤子配合使用）：

| 型別 | 手法 | 示例 | 留人原理 |
|------|------|------|---------|
| 視覺奇觀 | CGI特效、微縮景觀、定格動畫 | 小人在牙縫間清理牙垢 | 「沒見過」→ 停下來看 |
| 產品堆疊 | 大量產品同時入鏡、旋轉託盤碼放 | 買1發8全部擺出來 | 「好多東西」→ 佔便宜心理 |
| 畫面突變 | 前後對比、顏色突變、畫風切換 | 黃牙→白牙瞬間切換 | 視覺反差抓眼球 |
| 動作衝擊 | 誇張表情、快速手部動作、砸碎/撕裂 | 擠牙膏擠滿整支牙刷 | 動態>靜態 |
| 文字彈出 | 大字報、價格飛入、紅色X號疊加 | 「錯誤！」大紅X蓋在畫面上 | 資訊直給，0.5秒讀完 |
| 第一人稱POV | 手持展示、桌面俯拍、鏡頭直視 | 像在給你看東西 | 代入感強 |

**分析要點**（分析競品影片時必須逐項回答）：
- 文案鉤子：型別、完整轉錄、與產品的關聯度
- 視覺鉤子：型別、具體畫面描述（景別/色調/運鏡/特效）
- 文案×視覺配合：文案和畫面是否同步強化同一個資訊
- 第一幀畫面：暫停在第0秒，這一幀單獨截出來能不能吸引點選
- 聲音設計：前3秒有無音效/BGM變化/人聲語氣變化
- 鉤子強度評分（1-10）及理由

### 2. 分鏡結構

**逐鏡頭拆解**：
- 每個鏡頭的時長、景別（特寫/中景/遠景/俯視）
- 鏡頭之間的轉場方式（硬切/跳切/滑動/疊化）
- 鏡頭數量與影片總時長的比值（節奏密度）

**常見結構模板**：
- 鉤子→痛點→方案→效果→CTA（種草標準型）
- 鉤子→產品展示→使用演示→價格錨定→CTA（千川標準型）
- 鉤子→before→使用過程→after→CTA（對比型）

### 3. 節奏設計

**節奏要素**：
- 快切片段的時間點和持續時長
- 節奏變化如何配合內容推進（資訊密集處加快/賣點處放慢）
- BGM節奏與畫面剪輯的配合度
- 停頓和留白的使用（給觀眾消化時間）

**節奏模型**：
- 快-慢-快：開頭抓注意力→中間展示細節→結尾催行動
- 漸進加速：從平緩敘事到高潮CTA
- 脈衝式：每5-8秒一個小高潮

### 4. 視覺元素

**畫面分析**：
- 色調和濾鏡風格（暖調/冷調/自然/高飽和）
- 字幕出現時機、樣式、位置
- 貼紙/特效/花字使用
- 產品展示方式（手持/擺拍/使用中/效果對比）

**構圖分析**：
- 主體在畫面中的位置（中心/三分/對角）
- 背景選擇（純色/生活場景/專業場景）
- 景深使用（產品特寫的淺景深）

### 5. 轉化設計

**CTA（行動號召）分析**：
- CTA出現時機（結尾/中間/多次）
- CTA方式（口播/文字/引導評論/引導直播間）
- 價格錨定策略（原價→折後價/日均價/對比競品價）
- 緊迫感營造（限時/限量/贈品）

**轉化路徑**：
- 種草影片：影片→關注/收藏→搜尋購買
- 千川素材：影片→點選→直播間/商品詳情頁
- 短影片帶貨：影片→購物車→下單

### 6. 合規檢查

**廣審紅線**：
- 絕對化用語（最好/第一/100%/絕對）
- 未經驗證的功效承諾（包治/根治/永久）
- 虛假宣傳（誇大成分、偽造資料）
- 敏感對比（貶低競品、名人效應未授權）

**平臺規則**：
- 千川素材特殊稽核要求
- 類目特殊限制（食品/保健品/藥品/化妝品）
- 直播間引流素材的合規要點

### 7. 可複製要素提取

**核心問題**：這個影片的爆款要素，哪些可以直接複製到我的產品？

**提取清單**：
- 可複製的鉤子句式（替換產品名即可）
- 可複製的分鏡結構（同品類通用）
- 可複製的視覺風格（濾鏡/構圖/字幕樣式）
- 可複製的BGM節奏模式
- 可複製的CTA話術模板
- 不可複製的元素（獨特場景/特定達人/品牌勢能）

## 種草影片 vs 千川素材

| 維度 | 種草影片 | 千川投放素材 |
|------|---------|------------|
| 核心目標 | 建立信任、種草心智 | 直接轉化、ROI導向 |
| 時長 | 30-60秒 | 15-30秒 |
| 鉤子要求 | 引發共鳴/好奇 | 前3秒必須有強鉤子，資料型/痛點型 |
| 內容風格 | 真實感、分享感 | 資訊密集、賣點直給 |
| 口吻 | 像朋友推薦 | 像導購員推銷（但不能太硬） |
| CTA | 軟引導（關注/收藏） | 硬引導（點選/購買/進直播間） |
| 合規要求 | 較寬鬆 | 嚴格（千川稽核更嚴） |
| 素材來源 | 真人實拍為主 | 口播+產品展示/混剪 |
| 評判標準 | 互動率、完播率 | ROI、轉化率、CPM |

## 影片提示詞5要素

寫Gemini影片分析prompt或Seedance生成prompt時，確保包含：

1. **主體**（誰/什麼產品）
2. **動作**（做什麼/怎麼展示）
3. **環境**（在哪裡/什麼場景）
4. **風格**（什麼視覺風格/情緒）
5. **鏡頭**（特寫/中景/遠景/運鏡方式）

缺任何一個，AI就會自己腦補，結果往往偏離預期。
