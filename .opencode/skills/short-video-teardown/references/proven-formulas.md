# 已驗證的爆款公式庫

> 從實際競品影片分析中提煉的爆款公式。當使用者未提供競品影片時，作為基線參考。

## 通用爆款邏輯（跨品類）

### 前3秒生死法則

鉤子 = 文案鉤子 + 視覺鉤子，兩條線缺一不可。

**6種文案鉤子**（按效果排序）：
1. 反常識：打破日常認知（「90%的人洗臉方式都是錯的」）
2. 痛點：直擊使用者難題（「臉上的痘印怎麼都消不掉？」）
3. 資料：用具體數字（「這瓶精華28天淡斑率83%」）
4. 場景：還原真實畫面（「每次約會前我都要做這一步」）
5. 懸念：激發好奇（「千萬別讓你老公知道這個」）
6. 利益：直接拋好處（「拍1發6還送贈品」）

**6種視覺鉤子**（必須與文案配合）：
1. 視覺奇觀：CGI特效、微縮景觀、定格動畫
2. 產品堆疊：大量產品同時入鏡，佔便宜心理
3. 畫面突變：前後對比、顏色突變、畫風切換
4. 動作衝擊：誇張表情、快速手部動作、砸碎/撕裂
5. 文字彈出：大字報、價格飛入、紅色X號疊加
6. 第一人稱POV：手持展示、桌面俯拍、鏡頭直視

### 節奏模型

| 模型 | 描述 | 適用 |
|------|------|------|
| 快-慢-快 | 開頭抓注意力→中間展示細節→結尾催行動 | 種草+千川通用 |
| 漸進加速 | 從平緩敘事到高潮CTA | 故事型種草 |
| 脈衝式 | 每5-8秒一個小高潮 | 長影片（>60秒） |

### 通用轉化路徑

種草：影片鉤子 → 痛點共鳴 → 成分/功效信任 → 價格錨定 → 軟引導（關注/收藏）
千川：影片鉤子 → 賣點直給 → 價格錨定 → 硬引導（點選/購買/進直播間）

## 品類公式：口腔護理

> 來源：白老大美白牙膏競品影片分析（2026-02）

### 鉤子公式

最佳組合：**反常識 + 視覺奇觀**

| 要素 | 實證 |
|------|------|
| 文案鉤子 | 反常識型：「給大家示範一下牙膏的錯誤用法，直接沾水刷是不對的」 |
| 視覺鉤子 | 微縮CGI特效：小人在牙縫間清理牙垢，視覺奇觀製造「沒見過」效果 |
| 鉤子強度 | 9/10 |
| 為什麼有效 | 挑戰日常習慣（沾水刷）→ 觀眾想知道「那怎麼才對」→ 自然匯入產品 |

**可複製的鉤子句式**：
- 「給大家糾正一個關於[產品品類]的誤區」
- 「[日常行為]的方式都是錯的」
- 「[具體數字]%的人不知道[品類常識]」

### 分鏡結構（種草標準型，30秒）

| 階段 | 時長 | 內容 | 視覺 |
|------|------|------|------|
| 鉤子 | 0-3秒 | 反常識/痛點場景 | 視覺奇觀或畫面突變 |
| 產品引入 | 3-8秒 | 品牌背書+核心成分 | 產品45度角特寫+成分字幕彈出 |
| 功效展示 | 8-18秒 | 資料錨點+使用演示 | 實拍使用過程+效果對比 |
| 價格錨定 | 18-25秒 | 價格對比+優惠 | 黃色加粗價格字幕 |
| CTA | 25-30秒 | 購買指令 | 引導手勢+定格 |

### 核心邏輯

「先破後立」：先打破認知（你一直做錯了）→ 給出科學解釋（為什麼錯）→ 引入產品（這才是對的）→ 資料背書 → 促轉化

### 轉化策略

- 價格錨定：「比去一趟口腔診所便宜太多」（對比消費場景，非競品）
- 品牌背書：一句話帶過（「做了幾十年的品牌」），不展開
- CTA方式：「點下面連結直接買」+ 緊迫感（「今天拍還有贈品」）

### 合規要點（廣審重點）

- 用「緩解」不用「治好/根治」
- **時間+功效承諾必須模糊化**：「60秒緩解」→「用完嘴巴就舒服多了」（即使是產品官方資料，投放素材中也不能直接用）
- 不用絕對化用語（最好/第一/100%）
- 不能暗示替代醫療（「比去牙科便宜」可以，但不能說「不用去牙科了」）
- 用第一人稱體感代替資料：「我自己用了大半管，吃冰的也不怕了」比「臨床驗證60秒起效」安全

## 品類公式：美妝護膚

> 來源：卡姿蘭黑磁粉底液競品影片分析（2026-02）

### 鉤子公式

最佳組合：**利益 + 產品堆疊**

| 要素 | 實證 |
|------|------|
| 文案鉤子 | 利益型：「這就是大品牌的活動力度嗎？」 |
| 視覺鉤子 | 產品堆疊：旋轉木托盤上快速堆疊贈品+五彩紙屑特效，0→滿只需2秒 |
| 鉤子強度 | 9/10 |
| 為什麼有效 | 「好多東西」→ 佔便宜心理 + 疑問句引導停留尋找答案 |

**可複製的鉤子句式**：
- 「這就是[品牌名]的活動力度嗎？」
- 「買1發[X]，我直接看傻了」
- 「[品牌]這次是認真的嗎？」

### 分鏡結構（千川標準型，30秒）

| 階段 | 時長 | 內容 | 視覺 |
|------|------|------|------|
| 鉤子 | 0-3秒 | 利益/懸念開場 | 產品堆疊快速動態入鏡 |
| 贈品拆解 | 3-11秒 | 逐一展示贈品 | 快切（每0.8秒一個剪輯點） |
| 場景化展示 | 11-14秒 | 生活場景中使用 | 場景切換，車內/戶外 |
| 質地演示 | 14-22秒 | 上臉實測 | 特寫跟拍，左右對比 |
| CTA | 22-30秒 | 直播間引導 | 手抱產品+指向箭頭 |

### 核心邏輯

「暴力堆疊」：用贈品數量製造視覺衝擊 → 快速拆解每個贈品（維持資訊密度）→ 上臉實測建立信任 → 情感話術促單

### 轉化策略

- 價格錨定：不直接說價格，用「買1發8」讓使用者自行估算價值
- 情感話術：「口紅可以不買，但這個瞞著老公也要買」
- CTA方式：引導進直播間，非直接下單
- 緊迫感：「錯過可就沒有了」

### 合規要點（廣審重點）

- 用模糊真實表述（「瑕疵被遮得七七八八」）代替完美承諾
- **不用美白/祛痘等功效詞**：「提亮」「改善膚色」更安全
- 避免貶低競品
- 「瞞著老公」類話術在抖音電商屬常規，但其他平臺需注意
- 不能暗示「用了就變美」的因果關係，用「我覺得狀態好了很多」代替

## 公式使用指南

### 有競品影片時
1. 先用Gemini分析競品影片（Step 3）
2. 對比本檔案中的品類公式，驗證/補充
3. 生成指令碼時同時參考競品分析和本檔案

### 無競品影片時
1. 根據產品品類，選擇最接近的品類公式
2. 如果沒有完全匹配的品類，使用「通用爆款邏輯」
3. 生成指令碼時，在prompt中注入對應品類的鉤子公式和分鏡結構
4. 提醒使用者：無競品分析的指令碼可能缺少品類針對性，建議後續補充競品影片

### 新增品類
每次完成競品分析後，將新品類的公式追加到本檔案中，格式與現有品類保持一致。
