## 旁白與發音

8 句，其中「著急」用「招急」送 TTS：

```json
"speech": {
  "s2_0": "同船的人都替他招急，他卻不慌不忙，拿出小刀，在船舷上刻了一道記號。"
}
```

- 字幕仍為「著急」。
- 選定 `s2_0` 的 seed 2：`w1_0_s2.wav`，7.68 秒，結尾乾淨。
- 其他句用 2 個候選，選長度與尾端較乾淨的版本。

## 畫面上的實際修正

### S1 劍

- 一開始劍放在 `px + 0.92*mw`，整支在船外，像插在水裡。
- 改成 `px + 0.55*mw`、`py + 0.30*mh`，`rot_img(..., -25)`，斜靠船內。
- 落下：`p = smooth(t, 5.75, 6.25)`；`x+95p`、`y+55p²`、`rot=-25+100p`。
- 水花：`spray_img(120,60)` 扇形 7 線＋6 水滴；漣漪 3 圈、速度 55。

### S2 手

- 第一版：完整半身＋長袖，像浮空半身加旗子。
- 第二版：只留手部特寫，袖子仍是巨大三角，手掌像黑團。
- 第三版：加上彎曲短袖與拳頭，讀得出人但手仍像甲蟲。
- 最終方向：**袖口藏手，只露刀身**；或保留手但不要讓手大於刻痕。原則是「不要硬畫失敗的手」。

### S3 岸

- 原本深色多邊形＋直線頂邊，像木棧。
- 改成沙色 165、斷續濕邊、兩層蘆葦（9 與 7 根）、低矮放在右下。
- 岸不要壓到 y=930 以下的字幕區。

### 轉場

- 原本 `TR=1.6` 的 radial mask＋edge glow，在 6.0 與 31.0 產生巨大墨塊。
- 改成 `TR=0.9` 的「收墨到紙色→落墨」：

```python
if p < 0.5:
    A, R = A0 * (1 - smooth(p, 0, 0.5)), R0 * (1 - smooth(p, 0, 0.5))
else:
    k = smooth(p, 0.5, 1.0)
    A, R = A1 * k, R1 * k
```

### 標題／tag

- 原本標題 1 秒時仍是一團模糊墨；把 `sharp` 提前到 0.55、bleed 收在 0.55。
- tag 的 `p=(local-0.35)/0.9`，1 秒內可讀。

## 片尾

- 原 total 49.5，最後字幕 48.6 結束，只剩約 0.9 秒。
- 在 s3 的 segment 加 2.5 秒，total 52.0。
- 重跑 `audio`，音樂與淡出一起延長。
