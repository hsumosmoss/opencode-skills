# 水墨短片：實際踩過的坑

這份清單來自《刻舟求劍》第一支 52 秒水墨短片。每一條都是實際發生過、已修過的；新片先掃一遍，可以少走很多彎路。

## A. 語音與發音

### A1. 台灣讀音不能靠漢字直讀

- 「著急」在台灣讀 **ㄓㄠ ㄐㄧ**，不是「卓急」。
- 字幕保留 **著急**；TTS 發音稿用 **招急**。
- 做法：`script.json` → `speech: { "s2_0": "……替他招急……" }`。
- **先 A/B**：同一句生成「著急」與「招急」各 2–3 個 seed，聽完再決定。不要一次改全部。
- 其他可能的地雷：角色（腳色）、質量（質亮／質量取決於上下文）、重複（重複／蟲複）。遇到再測，不要憑猜測。

### A2. 尾端截斷

- VoxCPM2 偶爾會把句尾吃掉，尤其最後一個字是輕聲或句尾有引號。
- 每次生成後聽 **最後 0.3 秒**；不要只看波形長度。
- 有截斷就換候選／seed；必要時重新斷句，不要用淡出遮。
- 影片最後一句如果離 total 太近，片尾會像斷片；最後一幕要留 **2–3 秒**。

### A3. 48 kHz 與 44.1 kHz

- VoxCPM2 輸出 **48 kHz**；`build.py` 會依檔頭用 `resample_poly` 轉 44.1 kHz。
- 不要手動先轉檔再放進 `tts/`，否則 build.py 可能二次重取樣。
- `mix.wav` 應是 44.1 kHz、立體聲；`ffprobe` 確認。

### A4. Seed 與 manifest

- 多候選會產生 `cand/<key>_s<seed>.wav`；選定後複製成 `tts/<key>.wav`。
- `_manifest.json` 要記 `selected` 與 `speech_text`；下次才重現得出來。
- 只重做一句用 `--only s2_0`；不要重跑全部，否則其他句的長度與快取會變。
- 改了 `speech` 但沒有重生 TTS，等於沒改；改了 TTS 但沒有重跑 `build.py audio`，時間軸也不會更新。

### A5. Windows 編碼

- Python `print` 中文／emoji 會爆 `cp950`：

```powershell
[Console]::OutputEncoding=[System.Text.Encoding]::UTF8
$env:PYTHONIOENCODING='utf-8'
```

- PowerShell 讀寫 JSON 用 `Get-Content -Raw` 與 UTF-8；不要用預設 ANSI。

### A6. 字幕與發音稿不可混用

- `build.py` 用 `script["scenes"][].lines` 上字幕。
- `tts_vox.py` 只用 `speech` 覆蓋 TTS 文字。
- 不要為了好念去改字幕；字幕是觀眾看到的版本。

## B. 時間軸與片尾

### B1. `END_HOLD` 只套在 s9

- 模板的 `END_HOLD` 是舊片尾 `s9` 專用；本片最後是 `s3`。
- 只加 `TAIL` 不夠，尾端仍只有 0.5–1 秒。
- 在 segment 組裝處加：

```python
elif sc["id"] == "s3":
    info["dur"] = end - start + 2.5
```

- 加完一定要重跑 `build.py audio`，`mix.wav` 與 `timeline.json` 才會延長。

### B2. 最後字幕與 total 太近

- 最後一句字幕結束後至少留 2 秒；否則觀眾還沒看完字就斷片。
- `check_timeline.py` 會警告。最後字幕 end 應 ≤ `total - 2.0`。

### B3. 加長後音樂沒重做

- 音樂是依 segments 與 total 生成的；只改 timeline 不改音樂，淡出會提前。
- 重跑 `audio` 一次搞定 mix、音樂、字幕。

### B4. GAP / TAIL 不是美學工具

- `GAP` 太大會讓說書節奏散；太小會黏。
- 先讓 TTS 自然，再用 0.2–0.5 秒的 gap 微調；不要用 gap 掩蓋截斷。

## C. 轉場與文字

### C1. 大面積 radial mask + edge glow 會變墨塊

實際畫面：標題→S1 與 S2→S3 的邊界出現巨大黑／白變形蟲，像壞掉的遮罩。

原因：

```python
m = clip((p * 1.3 - F) / 0.15)
e = exp(...) * 0.4 * sin(pi * p)
A = 1 - (1 - A) * (1 - e)
```

`e` 在整個徑向邊界加墨，兩層又不斷混合，結果就是大墨塊＋雙重曝光。

修法：**收墨到紙色**。

```python
TR = 0.9
if p < 0.5:
    k = 1 - smooth(p, 0.0, 0.5)
    A, R = A0 * k, R0 * k
else:
    k = smooth(p, 0.5, 1.0)
    A, R = A1 * k, R1 * k
```

- 0.9 秒＝0.45 秒收墨、0.45 秒落墨；搭配旁白空檔。
- 中間會有一小段全紙色，這是刻意的；不要讓它超過 0.8 秒。
- 轉場期間不要有字幕；把字幕排在空檔之後。

### C2. 標題／tag 墨暈太久像污漬

- `InkText.alpha` 的 bleed 太大、太久，1 秒時標題還是一團黑。
- 把 sharp 提前、bleed 收短：

```python
sharp = smooth(p, 0.08, 0.55)
bleed = smooth(p, 0.0, 0.25) * (1 - smooth(p, 0.20, 0.55))
```

- 標題 `p=(t-0.4)/1.2`；tag `p=(local-0.35)/0.9`。
- 標題 1.5 秒內要可讀；tag 1 秒內要可讀。
- 印章另外用 `R` 圖層，不要跟文字一起暈。

### C3. 字距與引號

- `disp()` 曾多印一個全形空格在引號前，字幕變成「‵「別急」」。
- 修正後要重建 `timeline.json` 與 `mix.wav`；字幕是從 timeline 來的。
- 全形空格 `　` 只用來做語氣停頓；不要在引號前後亂加。

## D. 人物、船、劍

### D1. 劍不能浮在船外

實際錯誤：劍靜止時被放在 `px + 0.92*mw`，結果在船右舷外，看起來像插在水裡。

修法：

- 讓劍 **斜靠在船內側**：`sx0 = px + 0.55*mw`、`sy0 = py + 0.30*mh`，旋轉 `-25°`，劍尖落在船內。
- 劍是「滑出船舷」，不是從人手裡垂直掉落；斜靠的劍更有說服力。
- 如果要手持，手必須真的接在劍柄上；否則會像步槍／相機。

### D2. 落劍要有旋轉與加速度

- 只做垂直位移會像電梯。
- 用 `p = smooth(t, 5.75, 6.25)`；位移 `x + 95*p`、`y + 55*p*p`；旋轉 `-25 + 100*p`。
- 這樣會先滑、再翻、再落水；`p=0.5` 時劍是斜的，`p=0.9` 接近水平。
- 落水點要在船外，且水花要對得上劍尖。

### D3. 水花不要用一整排垂直線

實際錯誤：`spray_img` 用 14 條從底到頂的垂直線，結果像蘆葦或爆炸，不像水。

修法：

- 低矮扇形：7 條短線從水面往上／外散，長度 0.3–0.7 倍高。
- 加 5–6 顆小水滴。
- 漣漪 3 圈即可，速度 55，alpha 0.42；4 圈等距會像靶心。
- 水花壽命 0.7–1.0 秒；不要留太久。

### D4. 人物剪影

- 遠景人物不需要臉；但要看得懂頭、肩、身體、船。
- 近景半身如果切在胸口，會像浮空半身；要麼給完整身體，要麼只給手／袖。
- 人物前傾要與船身搖晃同步；不要只有人歪、船不動。

## E. 手、袖、刀（S2 最大坑）

### E1. 半身＋長臂會變成「浮空半身」

- 曾經畫了頭／肩／胸，手臂卻是一條很長的寬袖，結果像浮空半身加一條旗子。
- 要麼畫完整人物（含腿／坐姿），要麼不要畫身體。

### E2. 手部特寫的袖子不能是巨大三角旗

- 只讓袖從右緣伸入時，`detail_sleeve` 的寬度太大、尖端太尖，會像黑色旗子。
- 袖要做成 **帶狀**：右緣寬、袖口窄，有上緣／下緣／褶線，不要一個實心大三角。
- 袖口要有一圈較深的布邊，讓觀眾知道「這是袖口，不是身體」。

### E3. 手掌很容易變成黑團／甲蟲

- 五指分開畫，在大景別會變成黑團；加上淡掌心＋深指節，又會像甲蟲。
- 如果連續兩版都不像手，**不要硬畫**。改用：
  - 袖口藏手，只露刀身與護手；或
  - 刀柄從袖口伸出，刀尖對刻痕。
- 觀眾會自己補「手在袖子裡」；這比一隻失敗的手乾淨。

### E4. 刻痕不要畫成 M 或字母 V

- 兩條線＋一個三角形會變 M／閃電。
- 用簡單 V：左臂、右臂共用同一個頂點，加一個小暗楔。
- 刻痕尺寸不要大於手掌；刀尖要落在 V 的右臂或頂點，否則像在旁邊比劃。
- 刻痕在船外側（rail 下方），不要浮在 rail 上。

## F. 岸、蘆葦、水

### F1. 硬邊多邊形會像木棧／水泥平台

- 實際錯誤：岸是一塊深色多邊形，上緣一條直線，看起來像碼頭。
- 修法：
  - 沙岸填色調亮（約 165），不要用 100 的深灰。
  - 上緣改成斷續的濕邊，不要一條 6 px 黑線。
  - 加 2–3 條平行沙紋，不要太多。
  - 岸的高度壓低，放在畫面右下，不要擋字幕。

### F2. 蘆葦不要像柵欄

- 等距、同高、無葉的細線會像柵欄。
- 用兩層：`reeds1(320,320,n=9)` 與 `reeds2(260,280,n=7)`，高低錯落。
- 加少量葉片與穗；不要每根都一樣。
- 蘆葦要從岸上長出來，不要浮在水面。

### F3. 水面波紋

- 波紋是背景節奏，不要蓋過人物與字幕。
- 水花、wake、ripple 的 alpha 要低；大片深色會讓畫面變髒。

## G. 審查與渲染

### G1. 只看小圖會漏錯

- contact sheet 只看整體；手、劍、刀尖、岸邊要用 1:1 裁切看。
- 曾經在 contact sheet 看起來正常，放大後手掌是一團黑。

### G2. 只看 stills 不看邊界

- draft 的換幕、標題、tag、水花都要抽邊界幀；stills 只取 scene 中段會漏掉轉場災難。
- 用 `review_draft.py` 抽 scene 邊界 ±0.4 秒。

### G3. 渲染中改 build.py

- `do_video` 用 multiprocessing；子程序可能已載入舊碼。
- 渲染中改檔會讓不同 block 用不同版本，結果隨機。
- 等 render 完再改；改完重跑 `py_compile`。

### G4. 快取與舊 timeline

- 改字幕／TTS 後只跑 `stills`，畫面會用舊字幕；要跑 `audio`。
- 改 scene 後只跑 `draft`，stills 不會更新；要跑 `stills`。
- 交付前確認 `timeline.json` 的 `subs` 是最新版本。

### G5. 檔案路徑

- `build.py` 的 `HERE` 是 `scripts/`；TTS 放 `scripts/tts/`。
- `OUTDIR` 由 `script.json` 的 `output_dir` 決定；`OUTFILE` 由 `output_name` 決定。
- 不要把 `tts/` 放在專案根，`build.py` 找不到。

## H. 輸出與品質

### H1. draft 不是 final

- draft 是單次壓縮，拿來看動態；不要拿 draft 交片。
- final 是兩階段位元率控制，目標約 19.2 MB；仍要 `ffprobe` 驗證。

### H2. 最後一幀與音訊

- 最後一幕延長後，音樂淡出也要跟著延長；`audio` 重跑。
- 片尾不要突然黑屏；可以留紙色＋印章，或讓船漂走後留白。

### H3. 不要過度裝飾

- 墨點、飛鳥、印章、tag 都是節奏；太多會讓畫面像特效展示。
- 先確保剪影與動作可讀，再加一兩個墨點。
