# 簡譜記法規格與往返工作流

## 簡譜文字記法（純文字版，本 skill 三支腳本共用）

| 記號 | 意思 | 範例 |
|---|---|---|
| `1 2 3 4 5 6 7` | 首調唱名 do re mi fa sol la si | `5 6 5` |
| `0` | 休止 | `0 -`（休兩拍） |
| `'` | 升一個八度（上加點），可疊加 | `1'` = 高音 do、`1''` = 再高八度 |
| `,` | 降一個八度（下加點），可疊加 | `5,` = 低音 sol |
| `_` | 減時線：時值減半，可疊加 | `5_` = 半拍、`5__` = 四分之一拍 |
| `-` | 增時線：+1 拍 | `5 -` 或 `5-`（兩種都支援） |
| `.` | 附點：×1.5 | `5.` = 1.5 拍、`5.-` = 2.5 拍 |
| `\|` | 小節線（僅排版，忽略） | `1 1 5 5 \| 6 6 5 -` |
| 空格 | 分隔音符 | |
| `#` 行 | 註解/報告 header，**跳過不解析** | `# 1=D bpm=100 ...` |

預設：一拍 = 四分音符、`1` = C4(do)、大調。參數：`--bpm`（速度）、`--key`（`1=?`，如 C/G/D——首調記法轉調只改這個，數字不動）。

## 往返工作流

```
哼唱.m4a
  │ hum2midi.py  (--snap chromatic|scale, --bpm 量化, --min-dur)
  ▼
out.mid  ←── 比對驗證（音符數/音高逐音）
  │ mid2jianpu.py  (自動偵測調性 → --key auto)
  ▼
out.jianpu.txt   ← ★ 使用者只改這個檔的數字 ★
  │ jianpu2midi.py  (自動讀 header 的 1=X/bpm=NN；--key/--bpm 可覆蓋)
  ▼
back.mid
  │ fluidsynth + FluidR3_GM.sf2 → ffmpeg loudnorm
  ▼
back.mp3  → 使用者試聽 → 不對再改 txt
```

**交付鐵則：同時給 mp3（可聽）＋ jianpu.txt（可編輯）**，只給一個等于斷了修改迴圈。

## 哼唱抽取參數調校（hum2midi.py）

| 症狀 | 調整 |
|---|---|
| 一個音被切成多碎片 | `--min-dur` 調升（0.12→0.2） |
| 相鄰音黏在一起 | `--min-dur` 調降、或縮合併閾值（檔內 0.06s） |
| 微跑音、半音不穩 | `--snap scale --key N` 吸附到大調音階 |
| 節奏太散 | `--bpm 80` 量化到拍格（犧牲原速彈性，先問使用者） |
| 某段整段沒抽到 | 換氣處音量太小——請使用者重錄該段，或降低 `fmin/fmax` 範圍 |
| m4a/aac 報錯 | 已內建自動 ffmpeg 轉 wav，若仍錯先確認 ffmpeg 在 PATH |

管線：`librosa.pyin`（統計式，非神經網路）→ 中值濾波（9 幀窗）壓顫音/起音滑音 → 連續同音幀聚合 → 間隔 <40ms 合併 → 對齊後同音碎片再合併。

## 調性偵測與非調內音（mid2jianpu.py）

- 掃 12 個候選主音，取「調內音數 + 0.5×主音強調」最高者
- **非調內半音 → 就近吸附**到大調音階，並在 `#` header 列出全部吸附清單（例：`2.0s G#->G`）——**這些是音高差異的合法來源**，比對時不算錯誤
- 時值量化到半拍格線（0.5 beat = 60bpm 時 0.5 秒；100bpm 時 0.3 秒）

## 往返已知差異（比對時的預期，非 bug）

| 項目 | 預期 |
|---|---|
| 音符數 | **必須 100% 一致** |
| 音高 | 除 header 列出的吸附處外，逐音相同 |
| 起點時間 | **量化到半拍格線**（±半格），原速彈性消失——這是記譜法本質，不是抽取失準 |
| 總長度 | 可能與原檔差 1–2 拍（末音量化、換算殘差） |

## 實測驗證基準（重跑時的通過標準）

| 測試 | 基準 |
|---|---|
| 模擬哼唱盲測（顫音+呼吸破綻，小星星 14 音） | 修參數前 25 音（碎片）→ 修後 **12/14 音、7 個音高全對** |
| 真實哼唱（22.2s m4a） | 51 音抽出、音域 38-57、簡譜往返音符數 51/51、音高 39/51（12 處=已報告吸附） |
| 簡譜→MIDI 時值 | 16 拍 @100bpm = 9.6 秒（驗算時值編碼） |

## 往返曾踩的 bug（改腳本時別回歸）

1. `5 -`（有空格）的獨立增時線不被解析 → 已支援
2. BPM=0（未量化 MIDI 的 tempo 異常）→ `mid2jianpu` 防呆回退 100
3. 0.5 拍被誤記成 `__`（=0.25 拍）→ 對數編碼修正
4. 附點 `.` 回程不認 → 正則已加 `\.?`
5. m4a 不被 libsndfile 認 → 自動 ffmpeg 轉檔
